# 胶片六格素材规格单

配套：[reel-content-design.md](reel-content-design.md)
用途：照这个备料，交过来我直接能接进渲染管线，不用返工。

---

## 通用规格

**画幅**：每格 **4:3**，成品贴图 **1024 × 768**。
（现在图集是 4096×512 六格平分 = 683×512，太糊，会升级成每格独立贴图。）

**两种资产，每格都要**：

| | 用途 | 规格 |
|---|---|---|
| **静帧** | 这一格不在最前面时显示 | `1024 × 768` PNG 或 WebP |
| **动态序列** | 这一格转到最前面时播放 | 见下 |

静帧建议**直接从动态序列里挑一帧**，这样切换时不会跳。

---

## 动态序列规格（01 / 02 / 03 三格）

参考 shader.se 的做法——**不用 `<video>`，用预烘焙精灵表**。好处：帧能跟着拖拽精确擦洗，绕开浏览器自动播放策略，也不吃解码器。

**你只要给我原始录屏，切图我来做。** 但录的时候按这个来：

- **时长**：3~6 秒，且**首尾能接上**（循环时不跳）
- **帧率**：录 30 或 60fps 都行，我会抽成 12fps（更像胶片，也压得住体积）
- **分辨率**：越高越好，**至少 1440×1080**（4:3）或 1920×1080（16:9，我来做遮幅）
- **格式**：MOV / MP4 / 无损都行，**不要先压过一遍**

## 逐格清单

### 01 · JOI（Windows 实机）

**必须拍到的三拍**：
1. Joi 悬浮窗贴在屏幕边，正在读东西
2. agent trace 四步依次点亮：`OBSERVE → PLAN → APPROVE → REPORT`
3. **她停下来等你点同意的那一拍** ← 这是整格的重点，Joi 的产品主张就在这一停

**录之前清场**：桌面图标、任务栏通知、真实文件名、任何邮箱地址/人名 —— 全部清掉或换成假数据。这段会公开。

**建议**：录 1440×1080 窗口，或全屏录完我裁 4:3。

---

### 02 · JOI MAP（iOS 实机）

**动线**：`NEARBY 列表` → `抬起手机进 VISION 识别街景` → `ROUTE 起步导航`

**怎么录**（选一个）：

- **推荐**：iOS 屏幕录制（纯屏幕内容），我后期合进机身外框。干净、可控。
- 备选：真机实拍。有真实感但对布光和防抖要求高，容易翻车。

竖屏内容进 4:3 横画幅 —— 机身会斜放，两侧留呼吸空间，**所以纯屏幕录制反而更好用**。

**清场**：定位信息、真实地址、通知横幅。广州街景保留，那个真实感是加分项。

---

### 03 · 零刻：夜潮（Godot 实机）

**动线**：`弹反` → `BREAK 数字弹出` → `风格评级跳档` → `处决`，3~4 秒讲完战斗系统在追求什么。

**Godot 建议用 `--write-movie` 出无损帧序列**，比屏幕录制干净得多：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path ~/Documents/godot/ashen_blade --write-movie ~/Desktop/nighttide.avi
```

**画幅**：游戏是 16:9，进 4:3 格子我会做**遮幅**（上下黑边），这样更像宽银幕电影，比裁掉两侧好。

**已有可用**：`screenshots/night_tide_action.png`、`night_tide_boss_execution.png`、`night_tide_module_selection.png`、`night_tide_1920x1080.png` —— 静帧够了，**只缺那段录屏**。

### 04 · 实验室（接触表）

一格里排 **6~9 张小样**，每张 `340 × 256` 左右。

需要：

| | 内容 | 你要给的 |
|---|---|---|
| 头条 | 司天监夜话 | 概念图 / 立绘 / 任意能看的画面 1~2 张 |
| | CRT shader 研究 | 我来截，不用你管 |
| | Live2D 绑定 / 三维验证 | `live2d-working/`、`docs/design-references/joi-hunyuan-*` 里挑几张 |
| | 粒子开场 / doorway QTE | 我来截 |
| | （可选）类塔复盘 | `leitower/screenshots/` 里挑 1 张 + 一句"为什么砍" |

**司天监是这格唯一的硬缺口** —— 其它我基本能自己凑。

---

### 05 · 我的房间

**3D 场景**：卡通化的桌面空间。你可以直接给我 `.glb`，我接进 Three 场景做缓慢浮动；或者给我一张渲染图先占位。

**桌上物件建议 6~8 个**，每个对应一个兴趣点（显示器 / 键盘 / 手办 / 耳机 / 书 / 咖啡杯 / 游戏手柄……）——详情页里点物件跳到对应段落。

**详情页要的文字**：
- 个人照片 1~2 张
- 实习经历（公司 / 时间 / 你做了什么，一条一两句）
- 兴趣爱好，**按桌上物件分组**
- 简历 PDF

## 优先级

如果时间有限，按这个顺序：

1. **01 / 02 / 03 的录屏** —— 轮播的重心，三格全靠它
2. **05 我的房间的文字**（实习经历 / 兴趣）—— 不依赖 3D，可以先写
3. **06 联系信息** —— 五分钟的事
4. 04 实验室的司天监素材
5. 05 的 3D 场景 —— 最费时间，可以最后补，先用渲染图占位

前三项齐了我就能把胶片做成真东西，剩下的边做边补。
