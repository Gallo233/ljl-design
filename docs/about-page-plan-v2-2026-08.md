## P0 · 破相修复（根因已定位）

### 1. 终端半边花屏（根因：采样坐标系错误）
终端 canvas 被烘焙**图集 UV** 采样——那是图集打包坐标，不是 0–1 屏幕坐标，所以
半边黑、半边蓝绿噪点。
- [ ] 加载时从 `screen`/`screen.001` 几何的 `uv` 属性算出子矩形
      `[uvMin, uvMax]`，传 shader；终端采样改为 `fract((uv - uvMin) / (uvMax - uvMin))`
      重映射。烘焙底图仍用原 UV。对任何基座更换都稳健。

### 2. 猫与球不可见（根因：探针坐标是猜的，探空即隐藏）
GLB 真实坐标：椅子 (10.42, −4.25)、桌面 y≈5.7、地板 y≈0。
- [ ] Nick：探针落 **(10.42, −4.25)**，命中带 3.2–5.6（椅面），朝向桌子（lookAt
      屏幕方向）；探空兜底 = 直接放带内最高命中或 y=4.3。
- [ ] 篮球：**(12.2, −6.5)** 地板带 −0.5..2.0（椅子右侧空地）。
- [ ] 手套+棒球：桌面 **(3.4, 2.0)** 带 4.5–8.5（pen 与相机之间的空档）；
      篮球与手套拆成两个独立落位（一个 prop 两个 placement）。

### 3. 夜档「中毒」（根因：粉色辉光半径开到 9/7 单位包住落地灯 + tint 偏紫过饱和）
- [ ] LIGHT_PRESETS 重调：`night = tint(0.66,0.70,0.86) × 曝光 0.45`、
      `blue = tint(0.82,0.86,1.02) × 曝光 0.75`、`day = 1.0`——曝光因子并进共享
      tint uniform（等价 pinchen 的逐状态曝光表）。
- [ ] 辉光 sprite 重做：半径 9/7 → **2.4/2.2/2.6**；位置改为
      落地灯罩内 (2.89, 8.0, 8.59)、台灯头 (≈2.3, 7.1, −1.6，可调常量)、
      屏幕 (3.07, 5.80, −4.06)；颜色暖琥珀 `#ffc27a`，峰值透明度 ≤0.35。

### 4. 书「滑出」看不见（根因：方向算成了沿架长）
书架真实位置：墙面 x≈1.78、架面 y≈14.0、书沿 z 排列（−3.96 → −6.50）。
- [ ] 滑出方向固定 **+X（出墙方向）**，行程 0.9 → 1.4 单位。

## 重做项

### 5. 自由视角（球坐标轨道）
现有相机是「家↔焦点」两态 lerp，没有读者可控轨道。改为球坐标轨道：
- [ ] `orbit = { azimuth, elevation, distance, target }`，初值取自现 FULL_HOME
      视角；About 激活时**拖拽 canvas = 旋转**（azimuth ±70°、elevation 5–50°），
      双指/捏合与 ± 按钮 = 缩放（distance 18–55），带阻尼（lerp 系数同现有 0.09）。
- [ ] 与焦点拉近融合：pick 后 `target → 物件焦点`、`distance → 机位表距离`
      （复用 lerp）；关闭 sheet/Escape 后回到读者自己的轨道位，不回跳默认视角。
- [ ] deck player mode 维持现状，叠在轨道之上；reel 帧 05 的 frameCamera 不动。
- [ ] 拖拽与 reel/hero 的指针合同对齐（`roomOwnsPointer()` 内才吃拖拽）。

### 6. 书架 = 数据驱动的 3D 书（对齐 pinchen 的做法）
采集书是烘焙网格，拉不出来也高亮不了。改为真网格：
- [ ] `book1..book8` 采集网格 `visible=false`，在**原世界位姿**（node matrix 提取
      position+quaternion）放我们的书：Box 主体 + 书脊 canvas 贴图（竖排书名、
      cover/accent 色来自 `roomBooks.ts`），厚度 0.22–0.34 随数据微调，
      MeshStandard（吃道具灯组）。
- [ ] 点击某本书直接打开时间线并选中该书（raycast 返回带 `roomBook` 索引，
      `onRoomPick` 扩第二参）；hover 沿 +X 微探出 0.25 + emissive 提亮。
- [ ] 时间线选中 → 该书 +X 拉出 1.4；`book9/10` 无数据，保留采集网格。

### 7. 掌机按 Switch 重建
现模型厚 1.0 单位（≈12cm，真实 1.39cm），比例全错。
- [ ] 主板 2.06×0.88×0.12 + 两侧 JoyCon 轨道条（深色，各宽 0.34）+ 屏幕窗口
      1.35×0.62（现有像素循环屏保留）+ 摇杆/四键/十字键浅浮雕。
- [ ] 平躺桌面 (≈4.2, deskY探针, 0.4)，微转 ~20°，探针落位带 4.5–8.5。

### 8. 逐物件焦点机位表（用真实坐标）
- [ ] `crt-monitor` 焦点目标 = **屏幕中心 (3.07, 5.80, −4.06)**、距离 ~5
      （现在用整组 bounds 中心，导致「只放大看不见变化」）；
      `bookshelf` = (1.78, 14.3, −5.2)、距离 ~8；`camera` = (5.6, 4.9, 2.0)、
      距离 ~6；`poster` = poster.002 中心、距离 ~7；其余用 bounds 半径推导。
