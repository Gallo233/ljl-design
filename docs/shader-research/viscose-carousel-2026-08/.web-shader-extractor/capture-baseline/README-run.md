# Run the source-mechanism baseline

From `docs/shader-research/viscose-carousel-2026-08`:

```bash
python3 -m http.server 4178 --directory .web-shader-extractor/capture-baseline
```

Open `http://127.0.0.1:4178/` at 1512×870. Wheel or drag horizontally to separate the three cards; move the pointer quickly across their edges to see the melt halo and capillary wake.

This is not a clone of the upstream composition. It is an independently runnable baseline for the MIT-licensed mechanisms selected for ljl.design, with no upstream imagery or commercial fonts.
